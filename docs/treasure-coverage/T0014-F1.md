This report measures **new scenario mappings**, not validated game formulas or a revision of historical
T0013-F1 direct-damage coverage. The existing three snapshots and denominator remain byte-identical.
All calculated stack/proc projections are **Estimated**; duplicate/unsupported combinations are **Unavailable**.

accessed through the normalized repository. Exact full tier text and mappings for all **6 powers / 150 tier

## Reproduce

Run `npx vitest run src/core/calculation/damage-scenarios.test.ts` to check all 150 exact templates, selected-tier
math, 0/1/15 stacks, original-base Skill Base, removal/replacement, applicability, synthetic probabilities,
Burst/target totals, duplicate/unsupported cases, and critical separation.
Run `npm run coverage:treasure -- --check` to verify the unchanged historical reports.
The JSON is the direct projection of `SCENARIO_TREASURE_RULES` over each normalized power's tiers in numeric tier
order through `interpretTreasureEffect`: retain `category`, `value`, `scope`, optional `proc`, and exact tier text.
No source/generated snapshot was changed.
