## Behavior and evidence

Deliberate skill changes initialize an editable, autosaved effective level from
the matching resolved CharacterSheet snapshot. The skill/level change is one
validated edit, retaining the established per-bar clearing and staged-mod cleanup
with Undo. Imports and report replacement only replace the in-memory inventory.
Same-skill A+A levels and bars stay independent. Missing/unreliable mappings
retain the manual level with visible guidance. Level input text tracks external
commits while keeping incomplete typing and validation local.

[Corrected, customer-verified level interpretation](../../import/skill-levels.md):
**exported Level already includes BonusLevels**. Use Level directly; Prodigy
progression points never contribute. The previous third-party interpretation
was wrong for this CharacterSheet. Synthetic regressions verify Werewolf 106/6
→ 106, Deer 112/12 → 112, Cow 111/11 → 111 and Unarmed 110/10 → 110. Raw Level,
BonusLevels and metadata remain untouched. No private customer report was read.

For a selected skill with a valid differing imported value, **Apply imported
level** explicitly changes only that slot's level through existing autosave.
It hides when values match or no valid mapping exists and is disabled in
read-only drafts. It repairs previously inflated levels without an automatic
migration or clearing abilities, equipment, candidates, Sparks or other settings.

Each occupied icon now has an adjacent × button at its upper-right corner.
Desktop hover/focus reveals it; touch devices always show a 28px target. The
button comes before the icon in keyboard order so native popover focus behavior
does not obstruct quick removal. Stable sibling keys preserve numbered-add and
replacement focus restoration. Mouse, touch and Enter/Space remove exactly the
chosen entry and compact the bar. Focus restoration suppresses details activation;
the existing details-panel Remove remains available.

General bar + stays open through six additions with search, expansion, details
and scroll retained. A sticky live count and full-bar guidance stay readable
while scrolling. Numbered + and Replace close after one choice; full-bar Replace
keeps exact source IDs/ranks. Family markers and exact-tier duplicate counts
refer only to the current bar. Duplicates remain selectable until capacity.

## Real-browser verification

Chromium via installed Python Playwright, actual Vite dev (5180) and production
preview (4180), each at 1440×960, 375×960 and 320×960. Only synthetic reports were
used. CDN images were deliberately blocked to exercise the supported icon fallback;
these screenshots do not verify live CDN image loading. No page JavaScript errors
or horizontal document overflow. [Measured results](results.json).

Each scenario checks all four customer level regressions with synthetic Prodigy
metadata, manual levels surviving import/reimport, explicit repair from 95 to 90
without any other build change, six duplicate additions without picker remount,
retained search/expansion/scroll, live capacity, independent A+A bars, numbered +,
full-bar replacement and correct focus restoration.

Desktop uses actual hover/click and Enter. Mobile contexts emulate touch with
`has_touch` and `is_mobile`, use actual tap on a visible 28px ×, and Space after
Tab from the level input. Both removals are compared against exact expected
build snapshots, retaining the other bar. No removal opens a details popover.
Numbered empty slot 6 then appends into the next available slot 5 and closes;
fixed slot positioning is deliberately unchanged. Final levels are 90/102 and
bars are 5/1; refresh restores the exact saved build. See results.json for measured
nonzero scroll positions during all six additions.
