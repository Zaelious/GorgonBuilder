# GorgonBuilder Worker (T0019 review branch)

`index.ts` is the Cloudflare Worker entry. Static Assets serves the SPA; only `/api` and
`/api/*` reach this code (`assets.run_worker_first` in `wrangler.jsonc`).

- `api/router.ts`: health plus account routes; JSON 404/405, no SPA fallback for APIs.
- `api/accounts.ts`: allowlisted OAuth/session, username, ownership CRUD/copy and Public-only author APIs.
- `auth/`: pinned Better Auth options and canonical-origin/fail-closed environment gate.
- `api/dto.ts` and `src/persistence/remote/public-document.ts`: explicitly audited owner/non-owner response boundary.
- Native `D1BuildRepository` uses CAS writes; `0003_api_rate_limit.sql` supports shared atomic limits.
- `api/health.ts`: real `SELECT 1` on the `DB` binding; 503 `not_configured` when no D1 is bound (production remains unbound).
- `auth-probe/`: **local-only** Better Auth feasibility Worker (`npm run worker:smoke`). Not deployed and not mounted.
- `testing/`: test-only helpers.
- `worker-configuration.d.ts`: generated by `npm run worker:types` (run by `typecheck`); git-ignored.

Local commands (no Cloudflare account needed): `npm run build`, then `npm run worker:dev`
(applies migrations to `.wrangler/state` and serves http://localhost:8787) or `npm run worker:smoke`.
See [T0019 verification](../docs/T0019_Verification.md) and [website-only staging setup](../docs/T0019_Owner_Setup.md).
All hosted OAuth/migrations/deployment/CPU checks remain owner-action pending.
