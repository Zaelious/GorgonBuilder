# GorgonBuilder

Theorycrafting Project Gorgon builds to the extreme.

GorgonBuilder is a build planner and calculation tool for Project Gorgon. It is designed to go beyond item/mod selection by modeling ability damage, Mastery Sparks, build comparisons, character-report imports, and eventually stateful rotation/DPS, survivability, threat, and automated optimization.

## Project Roles

- **Customer / Product Owner:** Matt
- **Architect / Planner / Scrum Manager:** ChatGPT
- **Implementation Developer:** Codex

## Core Workflow

1. Product/architecture decisions are documented before implementation.
2. Work is split into small numbered tickets in `docs/Tickets.md`.
3. Codex implements one ticket per branch.
4. Every ticket must pass its acceptance criteria and manual verification.
5. ChatGPT reviews completion reports and pull requests before merge.
6. `docs/Repo_Current_State.md` is updated after completed work.
